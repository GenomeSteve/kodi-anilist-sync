WatchNixtoons2 AniList Sync v0.5.1 HOTFIX (beta)

Experimental: If you are seeing WatchNixtoons2 errors, first turn OFF both new background settings and verify whether the errors stop. Do not install this build unless you have isolated the issue or want to test the fix.

Install script.watchnixtoons.anilist-0.5.1-hotfix.zip

This hotfix prevents the background worker from issuing Files.GetDirectory requests that launch the WatchNixtoons2 plugin. It reads existing Kodi episode records only. Manually opening an episode list in WatchNixtoons2 remains possible; no change to streaming code. The background AniList tracker, existing completed ticks and private viewing store are unchanged.

For the first test, leave both new background modes OFF; then enable only Private watched+resume sync after playback works normally. If WatchNixtoons2 still fails with both OFF, the fault is probably unrelated to background syncing.

This is not the stable Kodi update channel. Hotfix PR and regression tests.
