GenomeSteve Kodi repository

Install the repository ZIP through Kodi's Add-ons browser:

  • repository.genomesteve.anilist-1.0.0.zip
  • repository.genomesteve.dailymotion.test-1.0.0.zip (Dailymotion test repository)

Once installed, choose Install from repository → GenomeSteve Kodi Repository → Program add-ons → WatchNixtoons2 AniList Sync.
